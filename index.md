## 🛠 Using the interface

The main window features a search bar at the top and a settings menu on the left. Type your question into the bar and press Enter. The software returns a list of matching documents found on your system.

- Search: Type keywords or full sentences.
- Documents: You can add new folders to the search library via the Settings menu.
- Filters: Narrow down results by date or file type.

If you have trouble finding a file, click the Refresh button in the settings menu. This makes the software scan your folders for new documents again.

## 🛡 Security and privacy

The software processes your files locally on your computer. Your document data stays on your hard drive. Only the text strings for your search queries move across the web to get intelligence results. You maintain full control over which folders the application scans. You can remove a folder from the settings menu at any time to hide those files from the search index.

## 📈 Troubleshooting common issues

If the software fails to open, check the following:

- Restart your computer to close any hanging processes.
- Ensure your antivirus software does not block the application. You might need to add the software folder to your exceptions list.
- Check your internet connection. The search features require a live connection to function.
- If the search results appear empty, verify that you chose the folder containing your documents in the Settings menu.
